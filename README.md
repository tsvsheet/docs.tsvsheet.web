# docs.tsvsheet.web

Public documentation for [`tsvsheet/tsvsheet.web`](https://github.com/tsvsheet/tsvsheet.web) — the [tsvsheet](https://github.com/tsvsheet/tsvsheet) grid editor: a standalone, fully client-side `.tsvt` spreadsheet editor on the WebAssembly engine — and for [`tsvsheet/tsvsheet.ui`](https://github.com/tsvsheet/tsvsheet.ui), the desktop app that embeds it. Published as a [Hugo](https://gohugo.io) site via GitHub Pages at [tsvsheet.github.io/docs.tsvsheet.web](https://tsvsheet.github.io/docs.tsvsheet.web/); contributor documentation (the host file port contract) lives unpublished in [`dev/`](dev/).
